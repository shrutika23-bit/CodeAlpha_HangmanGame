
# Hangman Game - CodeAlpha Internship

## Project Overview
This is a simple word-guessing game developed using Python as part of the CodeAlpha Python Programming Internship.

The player must guess a randomly selected word by entering one letter at a time. The player has six incorrect attempts to guess the word correctly.

## Features
- Random word selection
- Six attempts to guess the word
- Displays correctly guessed letters
- Tracks previously guessed letters
- Rejects invalid inputs
- Prevents repeated guesses
- Displays win or game-over messages

## Technologies Used
- Python
- Random module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   ```bash
   python hangman.py
   ```
